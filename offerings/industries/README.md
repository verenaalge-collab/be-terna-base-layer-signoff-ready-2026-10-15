## How to review

1. Name an accountable industry owner in each file.
2. Confirm the buyer definition and challenges.
3. Correct the proposed offering and platform mapping.
4. Add approved proof IDs from `proof/REGISTER.md`.
5. Replace the market placeholder with active commercial and delivery scope.
6. Change `status: draft` to `status: reviewed` only after resolving every note.
